# Бот учёта счетов-фактур (Telegram)

Минимальный бот: регистрация входящих/исходящих счетов-фактур, отметка оплаты, итоги за месяц, выгрузка CSV.
Данные — только локально в `invoices.db` на этом компьютере. Сторонних библиотек нет.

## Запуск
1. Установите Python 3.9+ с https://www.python.org/downloads/ (галочка «Add python.exe to PATH»).
2. В Telegram откройте @BotFather → `/newbot` → получите токен.
3. Скопируйте `config.example.ini` в `config.ini` и впишите токен.
4. Запустите `run.bat`, напишите боту `/myid`, впишите свой ID в `allowed_user_ids`, перезапустите.
5. Бот работает, пока открыто окно `run.bat`.

## Деплой на Railway
1. railway.com → **New Project** → **Deploy from GitHub repo** → выберите этот репозиторий.
2. В сервисе → **Variables** добавьте:
   - `BOT_TOKEN` (или `TELEGRAM_BOT_TOKEN`) — токен от @BotFather
   - `ALLOWED_USER_IDS` — ваш Telegram ID (несколько — через запятую)
   - `DB_PATH` = `/data/invoices.db`
3. В сервисе → **Settings → Volumes** (или правый клик → **Attach Volume**) → mount path `/data`.
   Без Volume база стирается при каждом редеплое.
4. Остановите локальный `run.bat`: два экземпляра с одним токеном мешают друг другу (ошибка 409 Conflict).
5. Проверьте **Deployments → Logs**: должна появиться строка «Бот @... запущен».

Бот — фоновый процесс (long polling), публичный домен и порт не нужны.

## Команды
| Команда | Что делает |
|---|---|
| `/add вх 125 09.11.2026 15000,50 Контрагент` | добавить счёт-фактуру (вх / исх) |
| `/list [N]` | последние N записей |
| `/unpaid` | неоплаченные и итог |
| `/paid <id>` | отметить оплату |
| `/del <id>` | удалить |
| `/find <текст>` | поиск по номеру / контрагенту |
| `/report [ГГГГ-ММ]` | итоги за месяц |
| `/export [ГГГГ-ММ]` | файл CSV (открывается в Excel) |

## Безопасность
- `config.ini` (токен) и `invoices.db` (данные) никому не пересылайте и не кладите в vault / облако.
- Чужие пользователи получают «Доступ закрыт».
- Переписка с ботом проходит через серверы Telegram — учитывайте это для конфиденциальных данных.
- Учётная система — 1С; бот — вспомогательный реестр, сверяйте с 1С через `/export`.
